# Фронтенд: Научная библиотека

## Требования
- Node.js 18+ (LTS рекомендуется)
- npm (ставится вместе с Node.js)

## Быстрый старт
- Установка зависимостей:
  - `cd frontend`
  - `npm install`
- Запуск dev-сервера:
  - `npm run dev`
  - Откройте `http://localhost:5173`
- Сборка продакшн-версии:
  - `npm run build`
  - собранные файлы будут в папке `dist/`

## Структура проекта
- `src/`
  - `app/`
    - `components/` — UI-компоненты (кнопки, карточки, фильтры, загрузчик PDF и пр.)
    - `contexts/` — контексты (авторизация, статьи, хранение в localStorage)
    - `pages/` — страницы и маршруты
    - `types/` — типы данных (Article, Tag, Citation и пр.)
    - `App.tsx` — декларация роутов
  - `styles/` — базовые стили/темы
  - `main.tsx` — точка входа
- `index.html` — шаблон страницы
- `vite.config.ts` — конфигурация Vite
- `package.json` — команды и зависимости

## Команды
- `npm run dev` — запуск локального сервера разработки
- `npm run build` — сборка проекта

## Данные и хранение
- Статьи и пользователь сохраняются в `localStorage` (см. `ArticlesContext.tsx`, `AuthContext.tsx`).
- При изменениях коллекций данные автоматически синхронизируются.


## Навигация и страницы
- Роуты описаны в `src/app/App.tsx`.
- Добавление новой страницы:
  - создайте файл в `src/app/pages/`
  - подключите его в `App.tsx` в список `Routes`

## Фильтры и поиск
- Фильтр по тегам — регистронезависимый, поддерживает выбор нескольких тегов.
- Выбранные теги отображаются под строкой поиска, удаляются по нажатию на крестик.

## Загрузка PDF
- Загрузчик поддерживает drag&drop и системный диалог выбора файла.
- Кнопки “Выбрать файл”, “Изменить файл”, “Удалить” — единый стиль.

## Метаданные
- На странице статьи доступна кнопка “Собрать метаданные” — сохраняет JSON с данными статьи.
